📌 Project Description
Daylog is a Telegram bot that helps users track and analyze how they spend their time during the day.
The user can send a simple text message describing their activities, for example: "watched YouTube for 2 hours and then did homework"
The system processes this input using AI and converts it into a structured format, such as:
* time spent
* activity tag (e.g., study, entertainment)
* description
* classification (useful or not useful)
  ⚙️ How It Works
1. The user sends a message to the Telegram bot
2. The backend processes the text using an AI model
3. The AI converts the text into structured data (JSON)
4. The data is stored in a database
5. The system can:
    * generate daily reports
    * send reminders
    * analyze productivity
    * calculate statistics of useful vs useless activities
      🎯 Goal
      The goal of the project is to help users become more aware of how they spend their time and improve their daily productivity.
